# 래쉬투고 찾아오시는 길 (PPT)

매장 위치 안내용 3장 슬라이드 자료입니다.

| 파일 | 설명 |
|---|---|
| `래쉬투고_찾아오시는길.pptx` | 원본 PowerPoint (16:9, 13.33 × 7.5 inch) |
| `래쉬투고_찾아오시는길_1~3.png` | 슬라이드 미리보기 (참고용 근사 렌더) |
| `build.js` | pptxgenjs 생성 스크립트 |
| `images/` | 슬라이드에 사용한 현장 사진 (크롭본) |

## 슬라이드 구성

1. **메인 안내** — 브랜드명 + 주소 + 마곡역 3번 출구 도보 1분
2. **3 STEP 경로** — 3번 출구 → GATE 1 통로 → GATE 4 엘리베이터
3. **도착 안내** — 3층 340호, 1층 랜드마크 체크포인트

## 안내 정보

- 주소: 서울특별시 강서구 마곡동 773, 힐스테이트 에코 마곡역 340호
- 교통: 지하철 5호선 마곡역 3번 출구 도보 1분
- 동선: GATE 1 통로 진입 → 안쪽 GATE 4(상가/오피스 엘리베이터 홀) → 3층 340호

## 다시 빌드하기

```bash
cd assets/rashtogo-directions
npm install pptxgenjs
node build.js          # images/ 의 사진을 참조하므로 해당 폴더에서 실행
```

## 이미지로 내보내기

PowerPoint에서 `파일 > 내보내기 > 그림 파일 형식으로 저장`을 선택하면
실제 폰트(맑은 고딕)가 적용된 고화질 이미지를 얻을 수 있습니다.
저장된 PNG는 참고용 근사 렌더이므로 자간·줄바꿈이 원본과 다를 수 있습니다.
